# Security policy

## Supported scope

This policy covers the current default branch and the GitHub repository,
validation, and release process for this public scholarly edition. It does not
describe a supported application, server, or runtime product.

Historical public-working releases are preserved scholarly and publication
records, not supported software versions. This reporting policy does not change
the rights, licenses, provenance, or review status of any repository content.

## Public reports

Use a [public GitHub issue](https://github.com/yaqub0r/al-isabah/issues/new) for
translation mistakes, typographical errors, scholarly disagreements, and
non-sensitive documentation problems.

Do not include credentials, secret values, restricted or private source text,
private paths, storage details, or other sensitive information in a public
issue.

## Private reports

Use GitHub's
[private vulnerability reporting](https://github.com/yaqub0r/al-isabah/security/advisories/new)
for:

- exposed or suspected credentials and secrets;
- restricted or private evidence exposure;
- private paths or storage details;
- vulnerabilities affecting workflow, validation, publishing, or release
  integrity; or
- any report whose details should not be public.

Please provide only the detail needed to investigate safely. Do not open a
public issue containing sensitive values or text.

## Response expectations

This is a solo-maintained scholarly project. Reports are reviewed and handled
on a best-effort basis, with private coordination when practical. There is no
formal response or remediation service-level agreement.
