# Al-Isabah Scholarly Platform

A platform-neutral scholarly edition and English translation of *al-Isabah fi
Tamyiz al-Sahabah* by Ibn Hajar al-Asqalani.

The permanent product is the versioned scholarly dataset: source evidence,
Arabic text, aligned English translation, editorial annotations, stable
identifiers, review state, and provenance. Web and future mobile applications
are clients of that dataset.

The repository is public. Public repository visibility does not by itself
authorize redistribution of every source binary; evidence manifests record
rights and publication status before assets are released.

[Sabiqah](https://github.com/yaqub0r/sabiqah) owns the public reader, review
editor, reviewer identity, and Cloudflare deployment. This repository owns the
canonical scholarly records, evidence, review pull requests, and releases that
Sabiqah and FirstLight consume.

Current work is tracked in [issue #1](https://github.com/yaqub0r/al-isabah/issues/1).
