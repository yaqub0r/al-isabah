# Artifact storage runbook

The repository contains scholarly records and artifact manifests. Large source
and generated bytes live in a private content-addressed store and a local
ignored cache. No command below changes canonical Arabic bytes.

## Build the migration manifest

```powershell
python scripts/artifact_store.py build-manifest `
  --inventory evidence/manifests/firstlight-migration.sha256.json `
  --output evidence/manifests/firstlight-artifacts.v1.json
```

## Stage and verify local evidence

```powershell
python scripts/artifact_store.py stage `
  --manifest evidence/manifests/firstlight-artifacts.v1.json `
  --source-root C:\path\to\FirstLight `
  --cache .runtime\artifacts

python scripts/artifact_store.py verify `
  --manifest evidence/manifests/firstlight-artifacts.v1.json `
  --cache .runtime\artifacts `
  --volume 8
```

`--artifact-id`, `--role`, and `--volume` can be combined. Empty selections are
errors so a misspelled selector cannot report a false successful no-op.

## Private R2 publication

Create a private bucket and an R2-scoped AWS CLI profile outside the repository.
The profile needs object read/write access only to this bucket. Then set
non-secret routing values (or pass their command-line equivalents):

```powershell
$env:AL_ISABAH_S3_ENDPOINT = "https://<account-id>.r2.cloudflarestorage.com"
$env:AL_ISABAH_S3_BUCKET = "al-isabah-private"
$env:AL_ISABAH_AWS_PROFILE = "al-isabah-r2"

python scripts/artifact_store.py publish `
  --manifest evidence/manifests/firstlight-artifacts.v1.json `
  --cache .runtime\artifacts `
  --volume 8
```

Do not place access keys, temporary signed URLs, or AWS profile files in Git.
The object key is the artifact SHA-256; publishing a revised artifact creates a
new object instead of mutating historical evidence.

## Hydrate one volume

```powershell
python scripts/artifact_store.py hydrate `
  --manifest evidence/manifests/firstlight-artifacts.v1.json `
  --cache .runtime\artifacts `
  --volume 8
```

Downloads remain in a temporary file until their size and SHA-256 match the
manifest. The local cache can be deleted and rebuilt; it is never authoritative.
