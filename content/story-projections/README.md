# Story projections

This directory contains deterministic, text-free structured projections from
immutable Al-Isabah public-working releases. They are consumer inputs, not
canonical promotion records or substitutes for the public distribution.

Each projection must have a versioned source-admission profile, a closed schema,
an exact immutable release pin, public rights and attribution, deterministic
generation, recursive public-boundary validation, and explicit correction and
supersession state.

Admission records source-report existence separately from critical status,
transmission strength, factual ambiguity, and story-use tier. A weak or
criticized transmission is retained as provenance metadata and is not, by
itself, a reason to discard historical context. Competing reports remain
parallel members of unresolved ambiguity sets so consumers cannot silently
select a resolution.

The current Khadijah projection is governed by the
[`elixr-approved-story-projection`](../../docs/contracts/elixr-approved-story-projection.md)
contract.
